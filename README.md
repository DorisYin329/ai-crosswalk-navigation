# AI 助盲道路導航模擬
AI-Assisted Road Navigation Simulation

## 專題介紹

利用 Minecraft 建立虛擬道路環境，搭配 Project Malmo 與 Q-learning，訓練 AI Agent 學習沿著指定道路行走及轉彎。透過調整環境觀察範圍與獎勵機制，探索強化學習在助盲導航上的應用，並另外進行 YOLOv8 道路環境辨識及 PPO 演算法實驗。

## 專題功能

- Minecraft 虛擬道路環境建置
- Q-learning 道路導航訓練
- 直線行走與轉彎訓練
- 獎勵機制設計與優化
- Q-table 儲存與載入
- 訓練曲線視覺化
- YOLOv8 道路環境辨識
- PPO 強化學習實驗

## 使用技術

- Python
- Minecraft
- Project Malmo
- Reinforcement Learning
- Q-learning
- YOLOv8
